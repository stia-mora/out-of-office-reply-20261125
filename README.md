A one-line out-of-office reply whose twist is that the auto-reply itself has gone on holiday too.

> I'm on holiday. Your email was forwarded to my out-of-office reply, which took one look and went on holiday too.

## Run

```bash
node main.ts
```

This writes the line to `/output/entry.txt` (creating `/output` if needed).

## Determinism

The program is fully deterministic: no randomness, no clock, no network, and no environment reads, so every run produces the exact same file.
